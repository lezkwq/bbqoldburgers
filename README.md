# BBQ OLD BURGER’S

Site estático adaptado da estrutura do Dom Menu para a hamburgueria BBQ OLD BURGER’S, em Gaspar/SC.

## Prévia local

Sirva esta pasta por HTTP: `python -m http.server 8080`. Abra `http://localhost:8080`.

Não há build. Publique a raiz do repositório em hospedagem estática. O runtime original (`support.js`) utiliza React, React DOM e Babel via unpkg; as fontes vêm do Google Fonts.

## Conteúdo

- Produtos e ingredientes transcritos dos materiais do cliente. Todos acompanham batatas rústicas.
- Fotos reais fornecidas pelo cliente, com limpeza de interface/textos e tratamento assistido por IA, exportadas em WebP.
